## When to read

Before EVERY generation step. Voice anchors title + description + tags. Boundary blocks publish if any check fails.

## Why two files

Voice = positive guidance ("sound like this"). Boundary = negative guidance ("never do this"). The agent reads both before drafting; they're orthogonal and both load-bearing.
